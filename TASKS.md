Each model should then take these parameters from the features normalization params Python file and bake them into register_buffers used by the input/output heads to the model for scaling of the inputs and outputs. We can set this up as an abstract base class called Model(nn.Module) that only wraps the internal model (one of the models currently in analysis/models/) in this input/output normalization scaling.
